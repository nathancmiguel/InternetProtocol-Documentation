The RTMP publisher streams video and audio from Unreal to any RTMP/RTMPS server: Twitch, YouTube, MediaMTX, nginx-rtmp, or another Unreal running an [`RTMP Server`](/docs/Unreal/rtmp-server). It captures the **viewport**, a **render target** or a **scene capture**, encodes H.264 on the GPU and AAC audio, and reconnects on its own. See the [RTMP overview](/docs/Unreal/rtmp) for complete flows.

<Callout type="warn" title="Requirements">
  -   The publisher lives in the `InternetProtocolMedia` module, which requires Unreal Engine 5.8 on Win64.
  -   It needs an **NVIDIA (NVENC) or AMD (AMF) GPU**: there is no software H.264 encoder. Without one of these GPUs, `Start` reports a clear error through `On Error`.
</Callout>

</Callout>

## How it works

-   **Video:** H.264 encoded by the GPU through the engine's AVCodecs: NVENC first, then AMF. There is no CPU readback. Frames are captured at the configured rate, up to the game frame rate.
-   **Audio:** AAC-LC at 48 kHz stereo, encoded by Media Foundation.
-   **Network:** `rtmp://` and `rtmps://`, with a bounded send queue. Under congestion P-frames are dropped first. Reconnection uses exponential backoff from 1 to 30 s, and a keyframe is forced after each reconnection.
-   The stream key is never logged: URLs are logged as `rtmp://host/app/***`, and `On Error` messages never contain it.

## Nodes

### Start

-   Starts publishing to `Url`: `rtmp://host[:port]/app` or `rtmps://host[:port]/app`.
-   `Stream Key` is appended as the stream name. Leave it empty if the URL already ends with it.
-   Returns false, and triggers `On Error`, on invalid input: bad URL, `Render Target` source without a render target, `Scene Capture` source without a scene capture, no supported GPU encoder...
-   `Width` and `Height` are rounded down to even values (minimum 16), and `Frame Rate` is clamped to 1-120.
-   If the `Submix` audio source has no audio device (audio disabled), it publishes video only and reports it through `On Error`.

## Structs and enums

### Publish Config

`FIPRtmpPublishConfig`, passed to [`Start`](#start).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `Video Source` | [`EIPPublishVideoSource`](#video-source) | `Viewport` | What is encoded as video. |
| `Render Target` | Texture Render Target 2D | none | Used when `Video Source` is `Render Target`. |
| `Scene Capture` | Scene Capture Component 2D | none | Used when `Video Source` is `Scene Capture`. If it has no `Texture Target`, one of the output size is created. |
| `Width`, `Height` | Integer | `1280` × `720` | Output size; the source is scaled. Even values, minimum 16. |
| `Frame Rate` | Integer | `30` | Capture rate (1-120). Frames are skipped when the game runs faster; it cannot exceed the game frame rate. |
| `Video Bitrate Kbps` | Integer | `4500` | Constant bitrate (minimum 100). |
| `Keyframe Interval Seconds` | Integer | `2` | 1-10. Twitch and YouTube require 2 s. |
| `Audio Source` | [`EIPPublishAudioSource`](#audio-source) | `Submix` | Where the audio comes from. |
| `Submix` | Sound Submix | none | Submix to capture. Empty uses the main submix. |
| `Audio Bitrate Kbps` | Integer | `160` | AAC-LC 48 kHz stereo: 96, 128, 160 or 192. |
| `Reconnect` | Boolean | `true` | Reconnect with exponential backoff (1 to 30 s) when the connection drops. |
| `Max Reconnect Attempts` | Integer | `0` | `0` retries forever. |

### Video Source

`EIPPublishVideoSource`

| Value | Description |
| --- | --- |
| `Viewport` | The game viewport's back buffer: what the player sees, UI included. |
| `Render Target` | A render target you draw into (materials, UMG widget renderer, canvas...). |
| `Scene Capture` | A scene capture component (another camera), captured at the publish frame rate. |

### Audio Source

`EIPPublishAudioSource`

| Value | Description |
| --- | --- |
| `None` | No audio track. |
| `Submix` | The engine's audio output: the main submix, or the one set in `Submix`. |
| `Manual` | Samples pushed with [`Push Audio Samples`](#push-audio-samples). |

### Publisher State

`EIPRtmpPublisherState`

| Value | Description |
| --- | --- |
| `Idle` | Not publishing. |
| `Connecting` | Connecting to the server. |
| `Publishing` | The server accepted the stream. |
| `Reconnecting` | Connection lost: retrying with exponential backoff. |
| `Error` | Stopped because of an error (see `On Error`). |

### Publisher Stats

`FIPRtmpPublisherStats`, returned by [`Get Stats`](#get-stats).

| Field | Type | Description |
| --- | --- | --- |
| `State` | [`EIPRtmpPublisherState`](#publisher-state) | Current state. |
| `Fps` | Float | Encoded video frames per second. |
| `Sent Kbps` | Float | Bytes actually written to the network, in kbit/s. |
| `Dropped Video Frames` | Integer64 | Video frames not encoded (encoder busy) or not sent (network congestion). |
| `Dropped Audio Frames` | Integer64 | Audio frames lost (capture overrun or network congestion). |
| `Queued Bytes` | Integer64 | Bytes waiting in the send queue. |
| `Rtt Ms` | Float | Round-trip time to the server in ms (-1 when unknown). |
| `Reconnect Attempts` | Integer | Reconnections so far. |
| `Video Encoder`, `Audio Encoder` | String | Name of the encoders in use. |
