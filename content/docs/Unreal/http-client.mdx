-   **New in 4.0.** Follows up to this many redirects (`301`, `302`, `303`, `307`, `308`) on the same host. A `303`, or a redirected `POST`, becomes a `GET`. Default `0`: redirects are delivered as responses.

### Request

-   Process payload and send request.
-   Requests are queued and sent one at a time over a single keep-alive connection, which is opened automatically when needed. You can call `Request` several times in a row.
-   The callback fires exactly once per request: with the response, or with an `Error Code` if the connection fails, the response is malformed, the connection is closed or `Close` is called.
-   For `HEAD` requests the response never has a body, whatever its headers say.
-   **Since 4.0:**
    -   It returns the request id, used by [`Cancel`](#cancel) and [`On Progress`](#on-progress).
    -   `Timeout Seconds` in the request fails it with `Operation timed out` when the response does not arrive in time.
    -   Binary bodies go in `Body Bytes`, and repeated headers (several `Set-Cookie`...) in `Header List`. See [HTTP Request](/docs/Unreal/options#http-request).
    -   Interim `1xx` responses (`100`, `103`...) are skipped.
    -   An idempotent request whose reused keep-alive connection closed before any response byte is sent again once, on a new connection.
