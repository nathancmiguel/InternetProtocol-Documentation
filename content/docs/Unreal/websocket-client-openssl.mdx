## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateWebsocketClientSsl`](/docs/Unreal/subsystem#create-websocket-client-ssl) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "websocket/wsclient.h"

    FSecurityContextOpts SecOpts = { ... };
    UWSClientSsl* client = NewObject<UWSClientSsl>();
    // Optional: without Construct, the secure defaults are used
    client->Construct(SecOpts);
    ```
  </Step>
</Steps>

## TLS options

-   `SecOpts` configures certificates, keys and verification. See [Security Context Options](/docs/Unreal/subsystem#security-context-options) for every field and its default.
-   Since 3.0.2 the connection is secure by default: TLS 1.2+, peer verification with the system root certificates and, for clients, host name verification + SNI.

<Callout title="4.0: one class for TLS and plain connections">
  Since 4.0, `WSClientSsl` is the [`WSClient`](/docs/Unreal/websocket-client) class with [`Use Tls`](/docs/Unreal/websocket-client#use-tls) turned on. You can also use a plain `WSClient`, set `Use Tls` or call [`Set Tls Options`](/docs/Unreal/websocket-client#set-tls-options) before connecting.
</Callout>
