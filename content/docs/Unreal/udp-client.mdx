## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateUDPClient`](/docs/Unreal/subsystem#create-udp-client) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "udp/udpclient.h"

    UUDPClient* client = NewObject<UUDPClient>();
    ```

  </Step>
</Steps>

<Callout title="Datagrams in 4.0">
  -   The receive buffer is 64 KiB by default (16 KiB before). Datagrams that do not fit are dropped and counted instead of closing the socket.
  -   When the Game Thread falls more than `Max Pending Receive MB` behind, new datagrams are dropped.
  -   Windows ICMP "port unreachable" resets (`WSAECONNRESET`) no longer close the socket.
</Callout>

### Connect

-   Resolve the address and connect asynchronously. `On Connected` is triggered when the connection is established, `On Error` if it fails.
-   It returns false if the socket is already open or connecting.
-   Since 4.0 you can bind a local address and port before connecting with `Local Address` / `Local Port` in the [Client Bind Options](/docs/Unreal/options#client-bind-options).

<UFunction
    name="Connect"
    className="UDPClient"
    pure={false}
    inPins={[
        { name: "", pintype: "exec" },
        { name: "Target", pintype: "object" },
        { name: "Bind Opts", pintype: "struct" },
    ]}
    outPins={[
        { name: "", pintype: "exec" },
        { name: "Return Value", pintype: "bool" },
    ]}
/>
