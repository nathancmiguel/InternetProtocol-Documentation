<Callout title="Routing">
  Requests are routed on the Game Thread to the callbacks below.

  -   A request whose path has no callback is answered automatically with `404 Not Found`.
  -   A malformed request is answered automatically with `400`, `413`, `431`, `501` or `505`, and the connection is closed.
  -   Requests pipelined on the same connection are answered in the order they arrived.
  -   Responses to `HEAD` requests are sent without a body.
</Callout>

<Callout title="Routes and parameters (4.0)">
  -   Routes are **case-sensitive**. Exact routes are tried first.
  -   `:name` segments and a trailing `*` capture values into `Route Params` of the request. For example `/users/:id` matches `/users/42` with `id = 42`, and `/files/*` matches everything below `/files/`.
  -   A path that exists only for other methods gets `405 Method Not Allowed` with an `Allow` header.
  -   `HEAD` falls back to the `GET` route when there is no `HEAD` route.
  -   `Expect: 100-continue` is answered automatically.
  -   A handler that sets `Connection: close` in the response closes the connection after it is sent.
  -   A handler that never calls `Write` gets an automatic `503` after [`Response Timeout Seconds`](#response-timeout-seconds).
  -   The parser rejects malformed headers (bare LF, folded lines, spaces before `:`), CR/LF in the path or host, HTTP/1.1 requests without `Host` and ambiguous framing.
</Callout>

## Remote

Each route callback receives the request and an `Http Remote` (`UHttpRemote`), the connection that will carry the response. Fill its `Headers` (status, headers and body) and call `Write`. In 4.0 the TLS server gives the same class: `HttpRemoteSsl` was merged into it.

### Headers

-   The response to send: `Status Code`, `Headers`, `Header List`, `Body` or `Body Bytes`. See [HTTP Response](/docs/Unreal/options#http-response).

<UVar
  pin={{ name: "Headers", pintype: "struct" }}
  get={true}
/>

### Write

-   Sends the response in `Headers`. Each request must be answered once.

-   **New in 4.0.** Starts a streamed response with the current `Headers` (status and headers, no `Content-Length`).
