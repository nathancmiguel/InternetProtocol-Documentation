The RTMP server accepts publishers (OBS, FFmpeg, another Unreal) and makes their audio and video available to an [`RTMP Receiver`](/docs/Unreal/rtmp-receiver). It can also let RTMP clients (VLC, ffplay, OBS) watch those streams. See the [RTMP overview](/docs/Unreal/rtmp) for complete flows.

<Callout type="warn" title="Unreal Engine 5.8 and DirectX 12 only">
  RTMP is supported only on **Unreal Engine 5.8**, **Win64**, with the **DirectX 12** RHI. Set *Project Settings > Platforms > Windows > Default RHI* to DirectX 12. On DirectX 11 or Vulkan the GPU encoder refuses to start, and publishing fails with an error.
</Callout>

## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateRTMPServer`](/docs/Unreal/subsystem#create-rtmp-server) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "rtmp/rtmpserver.h"

    URTMPServer* Server = NewObject<URTMPServer>(this);
    FServerBindOptions Bind;
    Bind.Address = TEXT("0.0.0.0");
    Bind.Port = 1935;
    Server->Open(Bind);
    ```
  </Step>
</Steps>

### Open

-   Opens the listening socket. The RTMP default port is `1935`.
-   It returns false if the server is already open or if any error happens during the bind. `On Listening` is triggered on success.
-   `Address` must be an IP literal, `localhost` or empty (any address). Host names are not resolved: they, and ports outside 0-65535, fail with an `Invalid argument` error.
-   Publishers connect to `rtmp://<this machine>:<port>/<app>/<stream key>`.

### Set Allowed Stream Keys

-   Restricts which stream keys may publish. An empty array accepts any key.
-   A publisher using a key that is not allowed is refused with `NetStream.Publish.Unauthorized`.
-   A second publisher using a key that is already live is refused (`NetStream.Publish.BadName`).
-   Keys are kept in memory only (never a saved property), so they never end up in versioned config.

## Playback

Playback lets RTMP clients (VLC, ffplay, an OBS *Media Source*, another Unreal) watch the streams published to this server. It is **off by default**. Viewers never get the publishing key: each stream is reached through a separate **view key**, at `rtmp://<this machine>:<port>/<app>/<view key>`.

-   Each viewer costs the full stream bitrate in upload bandwidth.
-   Each viewer has a bounded send queue: under congestion P-frames are dropped and the stream resumes at the next keyframe.
-   Viewers stay connected while the publisher reconnects.

### Set Playback Enabled

-   Allows RTMP clients to watch published streams. Applies immediately.
-   `Max Viewers Per Stream`: `0` means unlimited.

-   Lets viewers watch `App` / `Stream Key` by opening `rtmp://host:port/App/View Key`.
-   Returns false if `View Key` is empty or equal to `Stream Key` (that would reveal the publishing key).
