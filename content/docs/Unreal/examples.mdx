# Plugin Example

If you wish to test the websocket and http examples follow the instruction bellow.

## Setup

<Steps>
  <Step>
    Download [`Bun`](https://bun.sh/) and install
  </Step>
  <Step>
    Download [`Bun.zip`](https://github.com/nathancmiguel/InternetProtocol/releases) and extract file
  </Step>
  <Step>
    Go to `Bun` folder(extracted from Bun.zip), open terminal and type `bun run dev <resolver>`
  </Step>
  <Step>
    Change `<resolver>` by: `udp-client` `tcp-client`, `http-client`, `ws-client`, `udp-server` `tcp-server`, `http-server`, `ws-server`
  </Step>
  <Step>
    Now choose a unreal map and connect to server
  </Step>
</Steps>

# RTMP Example Map

The plugin ships an RTMP example map (UE 5.8, Win64, DirectX 12) that shows a live stream on a screen in the level and lets you publish from the editor.

<Steps>
  <Step>
    Open `/InternetProtocol/Example/RTMP/RtmpExample` and press **Play**.
  </Step>
  <Step>
    Press **Tab** to switch between the panel and moving around (WASD + mouse).
  </Step>
  <Step>
    Use the panel tabs:
    -   **Receive:** start an [RTMP server](/docs/Unreal/rtmp-server) and a [receiver](/docs/Unreal/rtmp-receiver), then stream to it from OBS or FFmpeg. Set an optional view key to watch the stream in VLC.
    -   **Play from a server:** pull any RTMP server's stream onto the screen.
    -   **Publish:** stream the viewport, the camera (scene capture) or a render target with the [publisher](/docs/Unreal/rtmp-publisher).
  </Step>
</Steps>

-   A light flash and a beep every second help judge audio/video sync.
-   The map and its material are generated by `Scripts/create_rtmp_example.py` (Python Editor Script Plugin), which you can run again to rebuild them.
