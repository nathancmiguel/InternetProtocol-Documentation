## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateWebsocketServerSsl`](/docs/Unreal/subsystem#create-websocket-server-ssl) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "websocket/wsserver.h"

    FSecurityContextOpts SecOpts = { ... };
    UWSServerSsl* WSServerSsl = NewObject<UWSServerSsl>();
    // Required: a TLS server needs a certificate and a private key
    WSServerSsl->Construct(SecOpts);
    ```

  </Step>
</Steps>

## TLS options

-   `SecOpts` configures certificates, keys and verification. See [Security Context Options](/docs/Unreal/subsystem#security-context-options) for every field and its default.
-   Since 3.0.2 the connection is secure by default: TLS 1.2+, peer verification with the system root certificates and, for clients, host name verification + SNI.

<Callout title="4.0: one class for TLS and plain connections">
  Since 4.0, `WSServerSsl` is the [`WSServer`](/docs/Unreal/websocket-server) class with [`Use Tls`](/docs/Unreal/websocket-server#use-tls) turned on. You can also use a plain `WSServer` and call [`Set Tls Options`](/docs/Unreal/websocket-server#set-tls-options) with a certificate and a private key before `Open`. The connections it accepts are the shared `WSRemote` class.
</Callout>
