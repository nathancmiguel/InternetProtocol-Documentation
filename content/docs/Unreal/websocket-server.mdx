  <Step>

## Variables

### Backlog

-    Set/Get the maximum number of simultaneous client connections the server will accept in queue.

<UVar 
  pin={{ name: "Backlog", pintype: "int" }}
  get={true}
/>

### Use Tls

-   **New in 4.0.** Encrypts the connection with TLS. With no [`Set Tls Options`](#set-tls-options) call, the secure default options are used.
-   Applies to the next connection.

<UVar
  pin={{ name: "Use Tls", pintype: "bool" }}
  get={true}
/>

### Sub Protocols

-   **New in 4.0.** Subprotocols supported, in order of preference. The first one the client offers is selected.

<UVar
  pin={{ name: "Sub Protocols", pintype: "fstringarray" }}
  get={true}
/>

### Ping Interval Seconds

-   **New in 4.0.** Remotes send a Ping after this much silence. Default `20`, `0` = never.

<UVar
  pin={{ name: "Ping Interval Seconds", pintype: "float" }}
  get={true}
/>

### Idle Timeout Seconds

-   **New in 4.0.** Remotes are closed (`Operation timed out`) after this much time without any frame from the client. Default `60`, `0` = never.

<UVar
  pin={{ name: "Idle Timeout Seconds", pintype: "float" }}
  get={true}
/>

### Open

-   Opens the TCP server and starts listening for incoming connections.
-   It returns false if socket is already open or if asio return any error code during the bind.
-   `Address` must be an IP literal, `localhost` or empty (any address). Host names are not resolved: they, and ports outside 0-65535, fail with an `Invalid argument` error.

<UFunction
  name="Open"
  className="WSServer"
  pure={false}
  inPins={[
    { name: "", pintype: "exec" },
    { name: "Target", pintype: "object" },
    { name: "Bind Opts", pintype: "struct" }
  ]}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Return Value", pintype: "bool" }
  ]}
/>

### On Upgrade Request

-   **New in 4.0.** When bound, every valid upgrade request waits for your decision: call [`Accept Upgrade`](#accept-upgrade) or [`Reject Upgrade`](#reject-upgrade) on `Client`, for example after checking the `Origin` header or a token in `Request`.
-   Requests left unanswered are dropped after `Handshake Timeout Seconds`.
-   When not bound, every valid request is accepted automatically.
-   A client asking for a wrong `Sec-WebSocket-Version` gets `426`.

<UEvents
  name="On Upgrade Request"
  showBindNode={true}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Client", pintype: "object" },
    { name: "Request", pintype: "struct" }
  ]}
/>

## Remote

Each client connected to the server is a `WS Remote` (`UWSRemote`), given by [`On Client Accepted`](#on-client-accepted), [`On Upgrade Request`](#on-upgrade-request) and [`Clients`](#clients). In 4.0 the TLS server gives the same class: `WSRemoteSsl` was merged into it.

-   **New in 4.0.** Accepts the upgrade request received in `On Upgrade Request`.
