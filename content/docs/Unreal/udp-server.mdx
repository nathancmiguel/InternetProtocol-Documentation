## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateUDPServer`](/docs/Unreal/subsystem#create-udp-server) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "udp/udpserver.h"

    UUDPServer* net = NewObject<UUDPServer>();
    ```

  </Step>
</Steps>

<Callout title="Datagrams in 4.0">
  -   The receive buffer is 64 KiB by default (16 KiB before). Datagrams that do not fit are dropped and counted instead of closing the socket.
  -   When the Game Thread falls more than `Max Pending Receive MB` behind, new datagrams are dropped.
  -   Windows ICMP "port unreachable" resets (`WSAECONNRESET`) no longer close the socket.
</Callout>

### Bind

-   Listen for datagram messages on a named port and optional address.
-   It returns false if socket is already open or if asio return any error code during the bind.
-   `Address` must be an IP literal, `localhost` or empty (any address). Host names are not resolved: they, and ports outside 0-65535, fail with an `Invalid argument` error.

<UFunction
    name="Bind"
    className="UDPServer"
    pure={false}
    inPins={[
        { name: "", pintype: "exec" },
        { name: "Target", pintype: "object" },
        { name: "Bind Opts", pintype: "struct" },
    ]}
    outPins={[
        { name: "", pintype: "exec" },
        { name: "Return Value", pintype: "bool" },
    ]}
/>

### Close

-   Close the underlying socket and stop listening for data on it. 'on_close' event will be triggered.

<UFunction
