## Variables

### Handshake

-   Set/Get handshake headers.
-   To offer subprotocols, set the `Sec-WebSocket-Protocol` header (for example `chat, json`). [`Get Sub Protocol`](#get-sub-protocol) returns the one the server selected.
-   Since 4.0 extensions cannot be requested (`Sec-WebSocket-Extensions`), and a server response that selects an extension or a subprotocol that was not offered is rejected.

<UVar 
pin={{ name: "Handshake", pintype: "struct" }}
/>

### Use Tls

-   **New in 4.0.** Encrypts the connection with TLS. With no [`Set Tls Options`](#set-tls-options) call, the secure default options are used.
-   Applies to the next connection.

<UVar
  pin={{ name: "Use Tls", pintype: "bool" }}
  get={true}
/>

### Ping Interval Seconds

-   **New in 4.0.** Sends a Ping after this much silence. Default `20`, `0` = never.

<UVar
  pin={{ name: "Ping Interval Seconds", pintype: "float" }}
  get={true}
/>

### Idle Timeout Seconds

-   **New in 4.0.** Closes the connection (`Operation timed out`) after this much time without any frame from the server. Default `60`, `0` = never.

<UVar
  pin={{ name: "Idle Timeout Seconds", pintype: "float" }}
  get={true}
/>

### Auto Reconnect

-   **New in 4.0.** Connects again after an unexpected close, waiting 1, 2, 4... seconds. Never after `Close` or `End`. Default `false`.
-   `On Close` fires for the lost connection, then `On Connected` again once reconnected.

<UVar
  pin={{ name: "Auto Reconnect", pintype: "bool" }}
  get={true}
/>

### Reconnect Max Delay Seconds

-   **New in 4.0.** Upper bound of the wait between reconnection attempts. Default `30`.

<UVar
  pin={{ name: "Reconnect Max Delay Seconds", pintype: "float" }}
  get={true}
/>

### End

-   Perform a smooth close of socket following ws protocol (RFC 6455 closing handshake) and stop listening for data on it. 'on_close' event will be triggered.
-   Sends a Close frame with `Code` and `Reason`, then waits up to 5 seconds for the peer's Close frame before closing the TCP connection.

  className="WSClient"

  inPins={[

-   Close the underlying socket immediately, without the closing handshake, and stop listening for data on it. 'on_close' event will be triggered with the given `Code` and `Reason`.
-   Prefer `End` for a clean disconnect; use `Close` to abort.

### On Close

-   Event triggered when socket is closed. It fires exactly once per connection.
-   Since 4.0 close codes `1012`-`1014` are accepted, and codes that cannot be sent (`1005`, `1006`, `1015`, unregistered) are replaced by `1000` when you call `End` or `Close`.
-   `Code` is the close code received from the peer (`1005` when it sent none), `1006` when the connection was lost without a Close frame, or `1002` / `1007` / `1009` when the plugin closed the connection because of a protocol violation, invalid UTF-8 or a message that was too large.

<UEvents
  name="On Close"
  showBindNode={true}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Code", pintype: "int" },
    { name: "Reason", pintype: "fstring" }
  ]}
/>
