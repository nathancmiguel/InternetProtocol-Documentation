## Variables

### Backlog

-    Set/Get the maximum number of simultaneous client connections the server will accept in queue.

<UVar 
  pin={{ name: "Backlog", pintype: "int" }}
  get={true}
/>

### Framing

-   **New in 4.0.** How the TCP byte stream is cut into messages: `Raw` (default), `Length Prefixed` or `Delimiter`. Both sides must use the same mode. See [TCP Framing Options](/docs/Unreal/options#tcp-framing-options).
-   Applies to the next connection (client) or to accepted connections (server).

<UVar
  pin={{ name: "Framing", pintype: "struct" }}
  get={true}
/>

### Use Tls

-   **New in 4.0.** Encrypts the connection with TLS. With no [`Set Tls Options`](#set-tls-options) call, the secure default options are used.
-   Applies to the next connection.

<UVar
  pin={{ name: "Use Tls", pintype: "bool" }}
  get={true}
/>

### Open

-   Opens the TCP server and starts listening for incoming connections.
-   It returns false if socket is already open or if asio return any error code during the bind.
-   `Address` must be an IP literal, `localhost` or empty (any address). Host names are not resolved: they, and ports outside 0-65535, fail with an `Invalid argument` error.

<UFunction
  name="Open"
  className="TCPServer"
  pure={false}
  inPins={[
    { name: "", pintype: "exec" },
    { name: "Target", pintype: "object" },
    { name: "Bind Opts", pintype: "struct" }
  ]}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Return Value", pintype: "bool" }
  ]}
/>

### Close

-   Close the underlying socket and stop listening for data on it. 'on_close' event will be triggered.

### Write

-   It returns false if the connection is closed, if the buffer is empty or if the send queue limit is exceeded.
-   With [`Framing`](#framing) enabled, the framing is added automatically.
