## How to use

<Steps>
  <Step>
    Blueprint: search by [`GetInternetProtocolSubsystem`](/docs/Unreal/subsystem#how-to-use) and call [`CreateTCPClientSsl`](/docs/Unreal/subsystem#create-tcp-client-ssl) function
  </Step>
  <Step>
    C++: Use the code bellow
    ``` cpp
    #include "tcp/tcpclient.h"

    FSecurityContextOpts SecOpts = { ... };
    UTCPClientSsl* client = NewObject<UTCPClientSsl>();
    // Optional: without Construct, the secure defaults are used
    client->Construct(SecOpts);
    ```
  </Step>
</Steps>

## TLS options

-   `SecOpts` configures certificates, keys and verification. See [Security Context Options](/docs/Unreal/subsystem#security-context-options) for every field and its default.
-   Since 3.0.2 the connection is secure by default: TLS 1.2+, peer verification with the system root certificates and, for clients, host name verification + SNI.

<Callout title="4.0: one class for TLS and plain connections">
  Since 4.0, `TCPClientSsl` is the [`TCPClient`](/docs/Unreal/tcp-client) class with [`Use Tls`](/docs/Unreal/tcp-client#use-tls) turned on. You can also use a plain `TCPClient`, set `Use Tls` or call [`Set Tls Options`](/docs/Unreal/tcp-client#set-tls-options) before connecting.
</Callout>
