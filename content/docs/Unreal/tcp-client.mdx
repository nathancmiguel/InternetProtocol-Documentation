## Variables

### Framing

-   **New in 4.0.** How the TCP byte stream is cut into messages: `Raw` (default), `Length Prefixed` or `Delimiter`. Both sides must use the same mode. See [TCP Framing Options](/docs/Unreal/options#tcp-framing-options).
-   Applies to the next connection (client) or to accepted connections (server).

<UVar
  pin={{ name: "Framing", pintype: "struct" }}
  get={true}
/>

### Use Tls

-   **New in 4.0.** Encrypts the connection with TLS. With no [`Set Tls Options`](#set-tls-options) call, the secure default options are used.
-   Applies to the next connection.

<UVar
  pin={{ name: "Use Tls", pintype: "bool" }}
  get={true}
/>

### Write

-   Sends string data on the socket.
-   It returns false if socket is closed, if buffer is empty or if the send queue limit is exceeded.
-   With [`Framing`](#framing) enabled, the length prefix or the delimiter is added automatically. A message larger than `Max Message Bytes` fails with `Message too large`.

<UFunction
  name="Write"
  className="TCPClient"
  pure={false}
  inPins={[
    { name: "", pintype: "exec" },
    { name: "Target", pintype: "object" },
    { name: "Message", pintype: "fstring" },
    { name: "Callback", pintype: "delegate" }
  ]}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Return Value", pintype: "bool" }
  ]}
/>

### Connect

-   Resolve the address and connect asynchronously. `On Connected` is triggered when the connection is established, `On Error` if it fails.
-   It returns false if the socket is already open or connecting.
-   Since 4.0 the connection must complete within `Connect Timeout Seconds` (15 s by default), and with `Protocol = Any` every resolved IPv4 and IPv6 address is tried. See [Client Bind Options](/docs/Unreal/options#client-bind-options).

<UFunction
  name="Connect"
  className="TCPClient"
  pure={false}
  inPins={[
    { name: "", pintype: "exec" },
    { name: "Target", pintype: "object" },
    { name: "Bind Opts", pintype: "struct" }
  ]}
  outPins={[
    { name: "", pintype: "exec" },
    { name: "Return Value", pintype: "bool" }
  ]}
/>
